CineScope - Site Plan

CineScope Movie Site

CineScope combines 'Cinema' and 'Scope' to represent a modern platform for exploring and discovering trending and popular movies.

Site Purpose

CineScope is a movie discovery website that allows users to explore trending, popular, and top-rated movies using real-time data from The Movie Database (TMDB) API. The site provides movie images, titles, brief overviews, and detailed movie information in an accessible, responsive, and user-friendly interface. The website is designed to help users quickly discover movies they may want to watch and learn more about them.

Scenarios

  • What movies are trending this week that I might want to watch?
  • How can I browse movies by popularity or rating?
  • Where can I see details about a specific movie?

Color Schema

Main Background: #0a0a0a - used for page background and light areas.

Surface Background: #161616 - used for Movie cards and sections

Primary Red: #e50914 - used Buttons, highlights, accents and UI highlights.

Text Primary: #ffffff - used for Headings and main text.

Text Secondary: #b3b3b3 - used for subtle background highlights, Descriptions and metadata.

Typography

  • Headings: "Poppins", sans-serif - for all major section and page headings.
  • Body Text: "Lato", sans-serif - used for readable paragraphs and content.
